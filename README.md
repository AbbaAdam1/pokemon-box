# Pokémon Box

**Pokémon Box** is a full-stack application that allows users to create an account, log in, and manage their personal Pokémon collection.

---

## Tech Stack
**Languages & Frameworks:** JavaScript, React.js, Next.js, Node.js  
**Styling:** Tailwind CSS  
**Database & Authentication:** PostgreSQL, Supabase  
**API:** REST API

---

## Features
- Implemented secure user authentication using Supabase
- Designed a relational database allowing CRUD  operations for Pokémon data
- Built a responsive and user-friendly interface with Tailwind CSS
- Developed RESTful API routes for smooth communication between frontend and backend

## Installation / Running Locally

**1. Clone the repository**

    git clone https://github.com/AbbaAdam1/pokemon-box

**2. Navigate to the project directory**

    cd Pokemon-Box

**3. Install dependencies**

    npm install

**4. Start the development server**

    npm run dev

Open http://localhost:3000 to view it in your browser.
